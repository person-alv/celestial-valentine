# Shadow Garden & Hub Sound Files Guide

This guide covers all the new sounds added during the "Shadow Garden" upgrade. Please place the files in their respective directories as listed below.

---

## 🏠 Hub & System Sounds
**Location:** `/public/sounds/hub/` and `/public/sounds/shadow-garden/sfx/`

### 1. **hub_lofi.mp3** (Place in `/public/sounds/hub/`)
- **Type**: Chill, lo-fi bedroom beat
- **Use**: Background music for the Cozy Bedroom Hub
- **Vibe**: Relaxing, study-beats style

### 2. **system_chime.mp3** (Place in `/public/sounds/shadow-garden/sfx/`)
- **Type**: Sharp, futuristic "ding" or system notification
- **Use**: Launching a game from the laptop, Solo Leveling system messages
- **Suggested search**: "UI confirm", "tech notification"

---

## 🎮 Shadow Garden Gameplay SFX
**Location:** `/public/sounds/shadow-garden/sfx/`

### 3. **combo.mp3**
- **Type**: Short, rewarding chime or "ding"
- **Use**: Triggered when a match-3 combo occurs (pitch-shifts up automatically)
- **Suggested search**: "game point", "collect item"

### 4. **infinity.mp3**
- **Type**: Deep "whoosh" followed by an electric hum (Gojo's style)
- **Use**: Activating the "Six Eyes" power
- **Suggested search**: "energy surge", "void sound"

### 5. **arise.mp3**
- **Type**: Dark whisper or shadow rising sound
- **Use**: Activating the "Shadow Army" power
- **Suggested search**: "shadow magic", "ghostly whisper"

### 6. **full_counter.mp3**
- **Type**: Metallic sword clash followed by a golden explosion
- **Use**: Activating Meliodas's "Full Counter" power
- **Suggested search**: "sword parry", "magic counter"

### 7. **domain_expansion.mp3**
- **Type**: Deep bass drop followed by an epic orchestral swell
- **Use**: The "Infinite Love" cinematic transition
- **Suggested search**: "cinematic boom", "universe expansion"

### 14. **vinyl_scratch.mp3** (Place in `/public/sounds/shadow-garden/sfx/`)

## Testing Checklist:

- [ ] Directory `/public/sounds/hub/` created and contains `hub_lofi.mp3`
- [ ] Directory `/public/sounds/shadow-garden/sfx/` contains all 6 SFX listed above
- [ ] Directory `/public/sounds/voice_notes/` contains your 5 recordings
- [ ] Music files are named exactly as listed (case-sensitive)
- [ ] All files work when tested in the browser console

---

**Tip:** If you are missing a file, the game will still run but you may see a 404 error in the console. You can use any free MP3 from sites like Freesound.org or Pixabay.com to fill these slots!
