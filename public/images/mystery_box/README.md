# Mystery Box Images

Drop your custom images here. Emojis (🎁 / 📦) are the immediate fallback if files are absent.

## Required files

| File | State | Notes |
|---|---|---|
| `box_closed.png` | Unopened S-Rank box | Shown with gold glow + bounce animation. Transparent PNG recommended. |
| `box_opened.png` | After reward is revealed | Shown greyed out / desaturated after opening. Transparent PNG recommended. |

## Sizing
The component renders these at 75% of an 80×80px container (≈60×60px effective).
Square or near-square art works best. High-res is fine — the browser will scale down.
